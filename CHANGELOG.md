### Features

* Click mode: hint labels on every clickable element, fuzzy text search
* Scroll, grid, window switcher, menu search and on-screen text (OCR) modes
* TOML config at `~/.config/pounce/config.toml` with hot reload, Settings window
* `pounce` CLI and `pounce://` URL scheme
* Nix flake with nix-darwin and Home Manager modules
